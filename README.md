# SakayPH - setup

All files sit in ONE folder (no subfolders).

1. Create `config.php` from `config.sample.php` on the server, with your real DB login and new secrets.
2. Import `schema.sql` in phpMyAdmin.
3. Upload everything (except `config.sample.php` if you like) to the web root (`htdocs`).
4. Open `index.html`.
